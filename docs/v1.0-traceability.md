# Invariant v1.0 requirement traceability

Every requirement ID of the v1.0 specification (24 October 2026), mapped to the
code and the tests that prove it. Status reflects this branch: the review fixes
for PR #1 (findings R1–R3), the shared analysis engine, rule and project
management with configuration import/export, the `forbidden_call` rule, the
`invariant` command line, stored results with their status, outcome,
counters and configuration snapshot, paginated history with statistics, the
queue and worker for GitHub analyses, the reliable GitHub path (one pull
request snapshot, download limits and one comment kept current), and one
error format with request IDs and structured logs, the API key with its
startup guard, and the limits, readiness and health checks.

- `done`: implemented, and the listed tests cover the acceptance criteria.
- `partial`: a base exists, but the v1.0 acceptance criteria are not met.
- `missing`: not implemented in this branch.

A row moves to `done` only together with the tests named in it. Test names are
`file::function` under `tests/`.
