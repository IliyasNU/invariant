# Invariant 1.1.1 final verification (9 November 2026)

This work completes the performance changes in `5e5ab25` on
`codex/v1.1-fixes`. Existing history was preserved. No merge into `main` was
performed; `main` still holds the older prototype.

## Final corrections

- Benchmark comparisons return a null speedup when results or workloads
  differ, with regression coverage for both cases.
- Prefix matching retains first-match order even when a caller mutates a
  validated list to contain duplicates.
- Retry-scheduling tests respect PostgreSQL's actual timezone instead of
  relabelling local times as UTC. The full suite was run against a server
  using `Asia/Qyzylorda`, which exposed and verified this correction.
- The C++ discussion distinguishes a standalone process from an unmeasured
  in-process extension. Native traversal can reuse the CPython AST; it does
  not inherently require a new parser. Profiler shares are not presented as
  wall-time speedup bounds.
- Historical evidence and C++ probe sources are now versioned under
  `benchmarks/`, so another machine can inspect and reproduce the experiment.
  Native binaries remain ignored and are not runtime dependencies.
- Setup examples and generated configuration links target this release
  branch instead of the outdated `main` branch. Pin a reviewed commit when
  adopting the example workflow in another repository.

## Local environment and limits

Docker Desktop was unavailable in this session (the Linux engine pipe did
not exist). No reset, volume deletion or host Docker repair was performed.
Instead, installed PostgreSQL 18 binaries initialized a new disposable cluster
under the workspace's `outputs/postgres-v111-final-20261109`. It listened only
on `127.0.0.1:55434`, with separate application and test databases. The API
was tested on loopback port 18012. Existing databases were not used.

The standard Docker build was not rerun for these changes. Docker definitions
and migrations were unchanged. No new schema migration is needed.

Real GitHub deliveries, comments and SARIF uploads were not performed. The
integration suite uses simulated HTTP responses. A 64-bit in-process native
extension remains unbuilt and unmeasured: the installed compiler targets
32-bit MinGW while Python is AMD64. C++ stays an optional experiment only.

## Commands

Run from the release checkout with Python 3.14 or later. Tests recreate their
database schema, so the PostgreSQL URL must identify a disposable database.

```powershell
uv sync --locked --dev
uv run pytest -p no:cacheprovider --basetemp=../../outputs/pytest-sqlite
$env:INVARIANT_TEST_DATABASE_URL = 'postgresql+psycopg://invariant@127.0.0.1:55434/invariant_v111_tests'
uv run pytest -p no:cacheprovider --basetemp=../../outputs/pytest-postgres
Remove-Item Env:INVARIANT_TEST_DATABASE_URL
uv run ruff check app benchmarks examples migrations scripts src tests
uv run ruff format --check app benchmarks examples migrations scripts src tests
uv run python -m compileall -q app migrations scripts src tests
uv run invariant check .
uv build
```

Native-probe and benchmark commands are documented in
[`benchmarks/README.md`](../../benchmarks/README.md). No credentials or
compiled native binaries are part of this release's source changes.
