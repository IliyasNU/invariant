## Findings not fixed (reported only)

- **Rate limits behind a proxy.** Limits count per client address, so
  behind a reverse proxy every client shares one bucket. This is documented
  in the README and #16 chapter 9. uvicorn trusts `X-Forwarded-For` only
  from `127.0.0.1` by default, and setting `FORWARDED_ALLOW_IPS=*` would let
  clients choose their own address. Adding per-client limits at the proxy
  is the documented answer.
- **`MAX_RULES` check-then-insert.** Two concurrent `POST …/rules` at 499
  rules can both pass, leaving 501 rules, which an export then cannot
  re-import. Low impact.
- **The webhook reads `Settings()` per request**, not
  `app.state.settings`, unlike the rest of the app. Not a production bug,
  since both read the environment, but `create_app(settings)` does not reach
  the webhook.
